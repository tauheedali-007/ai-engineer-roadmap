Har topic ka flow

Seekhne ki tarteeb

Udemy pehle, YouTube sirf jab atak jayein, GitHub repo apna version banane ke baad.

  1. Udemy (main source)

    Us hafte ke course ka agla lecture dekhein. Saath saath VS Code mein code type karein; sirf dekhna kaafi nahi. Week 1 aur 4 mein YouTube hi main source hai.

  2. YouTube Hindi/Urdu (sirf zaroorat par)

    Concept samajh na aaye to wahi topic CampusX ya Krish Naik par dekhein, maslan "RAG chunking". Poori playlist start na karein.

  3. Apna version banayein

    Wahi cheez apne bank/fintech example par khud likhein. Udemy ka chatbot ki jagah "bank policy bot".

  4. GitHub repo padhein (aakhir mein)

    Aapka version chal jaye, tab Resources wala repo khol kar compare karein. Ek achhi cheez apne code mein le aayein.

  5. Push karein

    Din ka kaam GitHub par commit, 5 line notes ke saath.

Kyun ye tarteeb: pehle repo padhne se code samajh aata hai magar khud likhna nahi aata. Pehle khud banane se interview mein aap apna har decision samjha sakenge.
